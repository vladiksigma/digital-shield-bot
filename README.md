# Цифровой Щит — Телеграм-бот

Чат-бот для противодействия интернет-мошенничеству среди подростков.

## Функции
- Информация о фишинге и способах защиты
- Правила безопасных онлайн-платежей
- Рекомендации по защите аккаунтов
- Справочник мошеннических схем
- Контакты для обращения за помощью
- Интерактивная викторина

## Запуск

```bash
pip install -r requirements.txt
export BOT_TOKEN="ваш_токен"
python bot.py
```

## Переменные окружения
- `BOT_TOKEN` — токен Telegram-бота от @BotFather
